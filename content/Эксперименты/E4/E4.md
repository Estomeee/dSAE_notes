## Описание
Исследовалось поведение фич, активировавшихся на данном токене, на последующих токенах последовательности, чтобы определить, как их активации изменяются и сохраняются в дальнейшем контексте.
Идея эксперимента состоит в том, чтобы для каждого токена определить, какие SAE-фичи активируются на нём, и затем проследить, как ведут себя именно эти фичи на следующих токенах последовательности.
## Предварительная гипотеза
Фичи наиболее сильно активны на токене, на котором они возникли, а на последующих токенах их активность постепенно снижается.
## Метод и условия
### Модель и данные
Аналогично E1: [[E1#Модель и данные]]
### Метод
Для каждого сэмпла сначала извлекаются активации всех токенов на выбранном слое модели. Затем с помощью SAE для каждой активации определяется набор соответствующих фич и значения их активаций.

Далее каждый токен рассматривается отдельно как точка возникновения его фич. Для данного токена мы выбираем все фичи, которые имеют положительную активацию на нём. После этого для каждой из выбранных фич смотрим, какое значение активации она имеет на каждом из последующих токенов.

Например, если на токене tt активировались фичи A, B и C, то мы отслеживаем значения A, B и C на токенах t+1t+1, t+2t+2, t+3t+3 и так далее. Затем для каждого расстояния от исходного токена усредняем активации A, B и C. В результате получаем кривую, показывающую, как в среднем меняется активность фич, возникших на токене tt, по мере продвижения по последовательности.

Такой анализ проводится для каждого токена. Таким образом, для каждого токена мы получаем «жизненный цикл» его фич: насколько сильно они активируются на самом токене и как их активация изменяется на последующих токенах.

После этого такие кривые агрегируются между сэмплами: отдельно усредняются кривые для токенов, находящихся на одной и той же позиции в последовательности и имеющих одинаковую длину последовательности. В результате для каждой позиции токена и каждой длины последовательности получается усреднённый жизненный цикл фич, возникших на этой позиции.
## Результаты
Эксперимент проведён для последовательностей пяти различных длин: 32, 64, 128, 256 и 512 токенов.

Для каждой длины последовательности построены графики жизненных циклов фич, возникающих на разных позициях последовательности. На каждом графике показаны пять характерных позиций: начало последовательности (0%), 20%, середина последовательности (50%), 80% и последний токен (100%). Для каждой из этих позиций отображается средний жизненный цикл фич, то есть изменение их средней активации на последующих токенах относительно токена, на котором эти фичи были впервые отобраны.
