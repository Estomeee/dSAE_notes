## Описание
Исследуется связь между признаками (features) SAE, активирующимися на усреднённых активациях сэмпла, и их поведением на отдельных токенах этого сэмпла.

Для каждого токена сэмпла извлекается вектор активаций на заданном слое модели. Затем активации всех токенов усредняются по позиции, в результате чего для каждого сэмпла формируется единый вектор, характеризующий его активацию на уровне всего текста. Этот вектор подаётся на SAE, после чего определяются признаки, активирующиеся на усреднённой активации.

Для каждого такого признака далее исследуется его поведение на исходных, неусреднённых активациях отдельных токенов того же сэмпла. В частности, оцениваются две характеристики: средняя величина активации признака среди токенов, на которых он активен, и частота его активации.

Основной исследовательский вопрос заключается в следующем: являются ли признаки SAE, активирующиеся на усреднённом представлении сэмпла, систематически более сильными или более частотными на отдельных токенах этого сэмпла по сравнению с другими активными признаками?
## Предварительная гипотеза
На усреднённой активации сэмпла преимущественно активируются те признаки SAE, которые на исходных активациях отдельных токенов этого сэмпла характеризуются высокой величиной и/или высокой частотой активации.
## Метод и условия
Для каждого сэмпла извлекаются активации всех токенов на заданном слое модели. Далее для каждого сэмпла рассматриваются два типа представлений.

Во-первых, активации всех токенов усредняются по токенам, в результате чего формируется единый вектор, характеризующий сэмпл в целом. Для этого усреднённого вектора с помощью SAE вычисляются активации признаков (features). Полученный набор фич используется для определения признаков, активирующихся на усреднённом представлении сэмпла.

Во-вторых, SAE применяется непосредственно к активациям отдельных токенов. Таким образом, для каждого сэмпла получаются активации SAE-фич на уровне отдельных токенов.

Для каждого сэмпла рассматриваются все SAE-фичи, которые активировались хотя бы на одной отдельной токеновой активации. Среди этого набора строится рейтинг фич. В режиме анализа величины активации фичи ранжируются по их средней активации, рассчитанной по всем токеновым активациям сэмпла, включая нулевые значения. В режиме анализа частоты фичи ранжируются по частоте их активации, то есть по доле токеновых активаций сэмпла, на которых соответствующая фича имеет ненулевую активацию.

Затем для каждой фичи, активировавшейся на усреднённом представлении сэмпла, определяется её позиция в рейтинге, построенном на основе отдельных токеновых активаций.

Для сравнения позиций фич между сэмплами используется **percentile rank**, поскольку количество активных фич может различаться. Сравнение абсолютных позиций в таком случае может быть некорректным: например, 30-е место среди 30 фич и 30-е место среди 1000 фич имеют существенно разную относительную значимость. **Percentile rank** отражает относительное положение фичи внутри рейтинга: первое место соответствует 100%, последнее — 0%. Это позволяет сопоставлять позиции фич между сэмплами независимо от количества активных признаков.

Активации снимались для `Gemma3-4b-pt` с `17 слоя` в точке [[2.1.2 Извлечение активаций|residaul]].
Использовался SAE от gemmaScope c l0 в 60: [17-GEMMASCOPE-2-RES-16K](https://www.neuronpedia.org/gemma-3-4b/17-gemmascope-2-res-16k).

Данные взяты из набора [high-quality-english-sentences](https://huggingface.co/datasets/agentlans/high-quality-english-sentences?utm_source=chatgpt.com). Эксперименты проводились для текстов различной длины: 32, 64, 128, 256 и 512 токенов. **Для каждого целевого значения длины отбирались тексты, фактическая длина которых отличалась от него не более чем на 10%. Для длины в 512 символов отличие длины может достигать 20%.** Для каждой длины использовалось по 5000 текстов.

## Результаты

В результате были построены violin plot, отображающие распределение percentile rank для фич, активирующихся на усреднённых активациях. Графики построены отдельно для сэмплов различной длины и для двух метрик: средней активации и частоты активации.

Привожу пример для текстов длины в 32 символа +- 10% от этой длины.
Все графики представлены на холсте [[Графики.canvas]].

![[freq_32_chars.png]]

По графикам видно, что в среднем фичи, активирующиеся на усреднённых активациях, занимают высокие позиции как по величине активации, так и по частоте активации на отдельных токенах. При этом с увеличением длины сэмпла данный эффект становится более выраженным.
