## Описание
Исследуется активация, усреднённая по токенам текста. Для каждого токена сэмпла извлекается активация на заданном слое модели. Затем активации всех токенов усредняются, в результате чего получается единый вектор, характеризующий сэмпл в целом.
Основной исследовательский вопрос заключается в следующем: возникают ли на усреднённой активации признаки (features) SAE, которые не активируются ни на одной из исходных активаций отдельных токенов этого текста?
## Предварительная гипотеза
На усреднённой активации не возникает фич, которые не активируются ни на одной из исходных активаций отдельных токенов этого текста.
## Метод и условия
Для каждого текста извлекаются активации всех его токенов на заданном слое модели, а также вычисляется усреднённая по токенам активация текста. Для каждой активации определяется множество SAE-фич, значения которых превышают заданный порог.
Для каждого текста формируется множество фич, активных хотя бы на одном из его токенов. Это множество вычитается из множества фич, активных на усреднённой активации текста. Таким образом, остаются фичи, которые активируются на усреднённом представлении текста, но не активируются на отдельных токенах.
Затем для каждого текста подсчитывается количество таких фич. В качестве итоговой метрики рассчитывается среднее количество фич, оставшихся после вычитания, по всем текстам.

Активации снимались для `Gemma3-4b-pt` с `17 слоя` в точке [[2.1.2 Извлечение активаций|residaul]].
Использовался SAE от gemmaScope c l0 в 60: [17-GEMMASCOPE-2-RES-16K](https://www.neuronpedia.org/gemma-3-4b/17-gemmascope-2-res-16k).

Данные взяты из набора [high-quality-english-sentences](https://huggingface.co/datasets/agentlans/high-quality-english-sentences?utm_source=chatgpt.com). Эксперименты проводились для текстов различной длины: 32, 64, 128, 256 и 512 токенов. **Для каждого целевого значения длины отбирались тексты, фактическая длина которых отличалась от него не более чем на 10%. Для длины в 512 символов отличие длины может достигать 20%.** Для каждой длины использовалось по 5000 текстов.
