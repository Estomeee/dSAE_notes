>[!important]- Основный формат, поддерживаемый соответствующими модулями  

**Формат датасета:** `.parquet`.

## Схемам данных

| Column |   Type   | Description                          |
| :----: | :------: | :----------------------------------- |
|   id   | `int64`  | Идентификатор примера                |
| source | `string` | Датасет, из которого был взят пример |
| domain | `string` | Категория примера: `harm` или `safe` |
| sample | `string` | Текст примера                        |

Пример схемы PyArrow:
```python
schema = pa.schema([
	("id", pa.int64()),
	("source", pa.string()),
	("domain", pa.string()),
	("sample", pa.string()),
])
```

Каждая строка датасета соответствует одному примеру. Поле `sample` содержит непосредственно текст примера в виде строки.

## Примеры

Пример записи:
```text
id source domain sample
1 dataset_a safe "Some example text..."
2 dataset_b harm "Another example..."
```
