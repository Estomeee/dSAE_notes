C целью выявления признаков, характерных для потенциально опасного (harm) контента выполнялся анализ сформированного словаря SAE.

Train части _датасетов для анализа harm и safe_ были независимо пропущены через обученный JumpReLU SAE. Для каждого признака отдельно на подмножестве harm и отдельно на подмножестве safe вычислялись следующие статистики:
- кол-во активаций;
- средний уровень активации;
- дисперсия активации.

> [!info]- Подробнее про статистики  
> Под __кол-вом активаций__ понималось кол-во примеров, на которых значение признака превышало порог активации и считалось ненулевым. __Средний уровень активации__ характеризовал интенсивность срабатывания признака, а __дисперсия__ отражала изменчивость его активаций на различных примерах.

Это позволило напрямую сравнивать распределения активаций между двумя классами данных.

Для каждой статистики были построены распределения значений по всему словарю признаков [^1]. Эти визуализации использовались для первичного анализа структуры словаря.
