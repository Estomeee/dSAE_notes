## Описание
В эксперименте применялась нормализация активаций фич JumpReLU SAE по индивидуальным порогам срабатывания. Каждая фича имеет обучаемый порог $θ_i$: при его превышении фича активируется, сохраняя значение предактивации. Таким образом, порог задаёт нижнюю границу ненулевых активаций, что следует из определения JumpReLU.

Нормализация выполнялась делением активации каждой фичи на её собственный порог:
$$\widetilde{a}_i(x)=\frac{a_i(x)}{\theta_i},$$
где $a_i(x)$ — активация i-й фичи после применения JumpReLU для входа $x$, а $\theta_i$ — соответствующий порог срабатывания.

Полученная величина выражает активацию **в единицах порога срабатывания**. Неактивные фичи сохраняют значение 0, а для активных фич нормализованное значение показывает, во сколько раз активация превышает порог. Например, значение 3 означает, что активация равна трём порогам данной фичи.

Такое представление позволяет сравнивать фичи по степени превышения их собственных порогов. При одновременном масштабировании активации и порога одной фичи на одинаковый положительный коэффициент их отношение остаётся неизменным.

Сопоставимость здесь относится именно к **активации относительно порога**. Одинаковые нормализованные значения сами по себе не означают одинаковую редкость активаций, одинаковый вклад в реконструкцию или одинаковое влияние на поведение модели.
## Предварительная гипотеза
**Предварительная гипотеза состоит в том, что такая нормализация изменит совокупное распределение величин активаций по фичам.** Поскольку у разных фич пороги различаются, деление на них по-разному масштабирует активации и может изменить относительное соотношение их величин, а также форму общего распределения.
## Метод и условия
### Модель и данные
Активации снимались для `Gemma3-4b-pt` с `17 слоя` в точке [[2.1.2 Извлечение активаций|residaul]].
Использовался SAE от gemmaScope c l0 в 60: [17-GEMMASCOPE-2-RES-16K](https://www.neuronpedia.org/gemma-3-4b/17-gemmascope-2-res-16k). ^563b32

Данные взяты из набора [just-user-prompts](https://huggingface.co/datasets/wop/just-user-prompts). Эксперименты проводились для текстов различной длины: **64** символов. **Для каждого целевого значения длины отбирались тексты, фактическая длина которых отличалась от него не более чем на 10%.** Для каждой длины использовалось по 1000 текстов.
### Метод
Для каждого текста извлекаются векторные представления всех его токенов на заданном слое модели. С помощью JumpReLU SAE для каждого токена вычисляются активации фич. Затем формируется множество фич, активных хотя бы на одном токене текста.

Для каждой фичи вычисляется средняя активация **по всем токенам текста, включая нулевые значения**.

При нормализации каждая активация делится на индивидуальный порог срабатывания $\theta_i$.  Поскольку порог фиксирован для каждой фичи, нормализация до и после усреднения эквивалентна:

Сравнение направлено на проверку гипотезы об изменении формы распределения и относительных величин средних активаций фич после нормализации по порогу.
